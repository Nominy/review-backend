Privacy Policy

Babel Gold Drafting

Babel Gold Drafting is a browser extension used to improve Babel transcript editing and turn existing transcript rows into a Silver-to-Gold draft. It processes task audio in the background to derive word timing metadata. Audio-enhanced drafting is enabled by default and can send audio to an AI model for audible-cue tags; users can disable it in settings. This page explains what transcript and audio data is processed and how it is used.

Last updated: 2026-08-29

Data the extension processes

The extension processes transcript content visible on https://dashboard.babel.audio/*, including current row text, row order, speaker labels, and timing values. It also captures the two task audio lanes and sends them to the configured L0 transcription endpoint to derive word start and end timestamps. This background request does not replace transcript text or send audio to OpenRouter. When audio-enhanced drafting is enabled, as it is by default, drafting requests may include task audio so an audio-capable AI model can add allowed audible-cue tags.

How data is used

The extension sends the minimum transcript payload required to the configured backend so it can:

  • generate a Silver-to-Gold draft for the current Babel job
  • optionally add allowed audible-event, vocal-style, emotion, and background-sound tags
  • align transcript words with audio timestamps for more precise editing and playback features
  • stream row-by-row drafting progress back to the extension
  • return the final draft so the user can review the diff before applying changes

The Chrome Web Store release build is locked to the production backend at https://reviewgen.ovh.

AI processing

The background L0 transcription service runs a speech-recognition model to return word timestamps used locally by editor features. It does not run the punctuation model or use the recognized text to replace the transcript. Silver-to-Gold drafting separately uses the OpenRouter API key provided by the user to add punctuation and formatting. When audio-enhanced drafting is enabled, task audio may also be sent to the selected audio-capable OpenRouter model. Users can disable audio-enhanced drafting in settings.

Local storage

The extension stores user settings in chrome.storage.local, including the drafting backend and L0 transcription URLs, selected project preset, OpenRouter API key, selected model, service tier, reasoning effort, and audio-enhancement controls.

Logging and retention

L0 task audio is processed transiently to produce word timing metadata; completed multipart scratch files are removed by the transcription service. The drafting backend may temporarily process transcript or audio-enhanced drafting requests to generate a response. The extension does not collect browsing history, search history, passwords, location data, or click-tracking analytics, and task audio is not used to build a separate reuse database.

Sharing

Data is processed only for the drafting workflow described above. It is not sold or shared for advertising.

Contact

For operational questions about the extension deployment, contact the team responsible for the Babel Gold Drafting service.
