Privacy Policy

Babel Gold Drafting

Babel Gold Drafting is a browser extension used to turn existing Babel transcript rows into a Silver-to-Gold draft. Audio input for audible-cue tags is an opt-in research preview. This page explains what transcript and optional audio data is processed, how it is used, and what the Chrome Web Store release sends to the production backend.

Last updated: 2026-05-16

Data the extension processes

The extension processes transcript content visible on https://dashboard.babel.audio/*, including the current row text, row order, speaker labels, and timing values needed to map the generated draft back onto the existing Babel rows. By default, it does not collect or send task audio. When the user enables the audio input research preview, it may also process task audio sources visible on the same Babel page so the backend can cut short row-level clips by the original segment timing.

How data is used

The extension sends the minimum transcript payload required to the configured backend so it can:

  • generate a Silver-to-Gold draft for the current Babel job
  • optionally add allowed audible-event, vocal-style, emotion, and background-sound tags
  • stream row-by-row drafting progress back to the extension
  • return the final draft so the user can review the diff before applying changes

The Chrome Web Store release build is locked to the production backend at https://reviewgen.ovh.

AI processing

The backend uses the OpenRouter API key provided by the user in the extension settings to add punctuation, formatting, and optional audio-cue tags to transcript rows. Default requests include transcript text and related row metadata only. If the user enables the audio input research preview, requests may also include short audio clips cut from the current Babel task audio when the selected OpenRouter model supports audio input.

Local storage

The extension stores user settings in chrome.storage.local, including the backend URL, selected project preset, OpenRouter API key, selected model, and whether the audio input research preview is enabled.

Logging and retention

The backend may temporarily process transcript requests to generate a response, but the extension itself does not collect browsing history, search history, passwords, location data, or click-tracking analytics. When the audio input research preview is enabled, task audio is used for the requested drafting response and is not a separate audio-overlap or reuse database workflow.

Sharing

Data is processed only for the drafting workflow described above. It is not sold or shared for advertising.

Contact

For operational questions about the extension deployment, contact the team responsible for the Babel Gold Drafting service.
